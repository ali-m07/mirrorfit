# حسابدار شخصی

اپلیکیشن وب ساده برای مدیریت درآمد، اقساط و بودجه ماهانه.

## اجرا

```bash
cd personal_accountant
python3 -m http.server 8080
```

سپس در مرورگر باز کنید: http://localhost:8080

## قابلیت‌ها

- ثبت درآمد ماهانه
- اقساط ثابت (دیجی‌پی، اسنپ، وام و...)
- اقساط موقت با تاریخ پایان (تقویم شمسی)
- هزینه‌های یک‌باره
- پیش‌بینی ۶ ماه آینده
- محاسبه بودجه روزانه و ماهانه
- ذخیره خودکار در مرورگر (localStorage)
